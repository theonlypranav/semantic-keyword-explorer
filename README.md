# Semantic Keyword Explorer

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://theonlypranav-semantic-keyword-explorer-app-z9wzkl.streamlit.app/)

**Live demo:** https://theonlypranav-semantic-keyword-explorer-app-z9wzkl.streamlit.app/

Paste a paragraph and get its 10 most representative keywords. Each keyword is scored with sentence embeddings for **relevance** (how close it is to the paragraph) and **overlap** (how close it is to the other keywords). The results show up as an interactive keyword constellation with an overlap-threshold slider. Everything runs on open models (`sentence-transformers`), with no paid API calls.

## Features
- 1–2 word candidates, ranked by cosine similarity to the paragraph embedding (the KeyBERT algorithm). **MMR** is on by default to remove near-duplicates.
- Long paragraphs are split into sentence windows. Each window is embedded on its own and the results are averaged, and the app shows a notice when this happens.
- Keyword table, plus a **constellation**: the paragraph sits at the centre and more relevant keywords are bigger and closer. Links appear between keyword pairs whose overlap is at or above the slider threshold.
- Choose "Why did this keyword rank here?" to see the keyword's closest partner and the sentence that supports it most.
- **Gold keywords** add semantic precision at 10 at thresholds 0.6, 0.7 and 0.8, plus a list of missed gold terms.
- Dark theme with beige highlights. All colour tokens live in [core/theme.py](core/theme.py); a test checks WCAG AA contrast.
- Downloads: `results.csv`, `results.json` (both include model, MMR setting, theme, threshold and timestamp) and standalone HTML charts.

## Setup
```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```
The first run downloads the model (~90 MB for MiniLM, ~420 MB for mpnet). Embeddings are cached in `.cache/`.

## Tests
```bash
pytest -q
```
The tests cover relevance, overlap, link-count monotonicity, precision at 10, nearest-neighbour accuracy and ARI, input limits and windowing, and WCAG AA contrast for the dark theme.

## Layout
```
app.py            Streamlit UI only
core/preprocess   cleaning, sentence split, limits, windows
core/embed        model loading, cached embeddings
core/extract      candidates, ranking, MMR, KeyBERT cross-check
core/similarity   relevance, redundancy, matrices
core/evaluate     precision@10, NN accuracy, ARI, failure pairs
core/project3d    UMAP (seed 42), keyword angles via PCA
core/viz          3D constellation (plus sentence-set charts used offline)
core/theme        colour tokens, CSS, Plotly layout, contrast checks
core/export       CSV / JSON / HTML
```

## Results
See [RESULTS.md](RESULTS.md). It was generated by `python scripts/evaluate.py` and covers MMR on vs off, precision on the gold paragraphs, and sentence-set accuracy and failure cases (offline only).

## Known limitations
- Streamlit gives limited control over clicks inside charts. Keyword drill-down uses a selector instead of clicking a point.
- The gold keywords were written by one person, so the precision numbers are indicative only.
